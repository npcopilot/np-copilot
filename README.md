# NP Copilot

A helpful assistant for nurse practitioners.

## Features

- Clinical decision support
- Patient documentation
- Drug reference

## Getting Started

Clone the repo and open in your editor of choice:

```bash
git clone https://github.com/npcopilot/np-copilot.git
cd np-copilot
```
